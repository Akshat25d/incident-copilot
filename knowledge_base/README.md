# Knowledge base

Documents the incident copilot searches during an investigation.

- `runbooks/`: generic troubleshooting procedures (RB-xxx)
- `service_docs/`: facts about the demo system (SD-xxx)
- `postmortems/`: past incident reports (PM-xxx)

All postmortems are synthetic: fictional incidents written for this project. The runbooks and service documents are written for the demo shop and follow common operations practice.
